# เป๋าตังค์ 🐷💗 (หลายผู้ใช้)

แอปบันทึกรายรับ–รายจ่ายบนมือถือ **ลิงก์เดียว ใช้ได้หลายคน** แต่ละคนสมัครด้วยอีเมล + รหัสผ่านตัวเลข 6 หลัก (กดปุ่มตัวเลขตอนเข้าสู่ระบบ) (ยืนยันอีเมล / ลืมรหัสผ่านผ่าน **Supabase**) แล้วเห็นเฉพาะข้อมูลของตัวเอง แนบสลิปโอนเงินแล้วแอปอ่าน QR บนสลิปให้ (ธนาคาร + เลขอ้างอิง กันบันทึกซ้ำ) ติดตั้งไว้ที่หน้าจอโฮมได้เหมือนแอปทั่วไป

> **ข้อมูลของผู้ใช้ทุกคนเก็บไว้ที่ผู้ดูแลระบบ**
> รายการทั้งหมดอยู่ใน Google Sheet และรูปสลิปอยู่ใน Google Drive **ของบัญชีผู้ดูแล** (คนที่ติดตั้งแอปนี้)
> ผู้ดูแลเปิดดูข้อมูลของทุกคนได้ และเป็นผู้รับผิดชอบดูแลข้อมูลส่วนบุคคลของผู้ใช้ (เช่น ตาม พ.ร.บ.คุ้มครองข้อมูลส่วนบุคคล)

**ฟรี:** Google (Sheet / Drive / Apps Script), GitHub และ Vercel แผนฟรีเพียงพอสำหรับกลุ่มเล็ก ๆ (ดู [ข้อจำกัด](#ข้อจำกัดของแผนฟรี))

## ฟีเจอร์
- **📎 สลิป** — เลือกได้หลายรูปพร้อมกัน แอปอ่าน QR (ธนาคาร + เลขอ้างอิง กันบันทึกซ้ำ) และถ้าเปิด AI จะอ่าน **ยอดเงิน วันที่ ชื่อผู้รับ และเดาหมวด** ให้อัตโนมัติ
- **＋ จดรายการ** — จดรายรับ/รายจ่ายที่ไม่มีสลิป
- **ดูตามวัน** — แถบเลือกวันใต้การ์ด (มีจุดสีประจำวัน + แถบบอกยอดจ่าย), หัวข้อแต่ละวันบอกวันในสัปดาห์ และทุกรายการแสดงเวลาที่บันทึก
- **ปฏิทินรายจ่าย** — ในหน้าสรุป สีชมพูเข้มตามยอดจ่ายของแต่ละวัน แตะวันเพื่อดูรายการวันนั้น
- **ธีมหวาน ๆ** — พาสเทลชมพู–ลาเวนเดอร์, กระจกใส, แอนิเมชัน, น้องหมูมาสคอต, หัวใจลอยตอนบันทึก, รองรับโหมดมืด
- **เปิดเร็ว** — จำข้อมูลล่าสุดไว้ในเครื่อง เปิดแอปเห็นทันทีแล้วค่อยซิงค์
- **แก้ไข / ลบ** — แตะรายการ → ✏️ แก้ไข (เปลี่ยนสลิปได้) หรือ ลบ
- **ค้นหาและตัวกรอง** — ค้นหาทุกเดือน, กรองตามประเภท หมวด บัญชี
- **บัญชี/กระเป๋า** — เช่น เงินสด, กสิกร, SCB — เลือกให้อัตโนมัติจากธนาคารในสลิป
- **📊 สรุป** — กราฟวงกลมตามหมวด, กราฟแท่ง 6 เดือน, ยอดแต่ละบัญชี
- **วงเงินใช้จ่ายต่อเดือน** — แถบบนหน้าหลัก บอกยอดที่เหลือและ "ใช้ได้อีกวันละกี่บาท" เตือนเมื่อถึง 80%
- **งบประมาณรายหมวด** — แถบความคืบหน้า และเตือนเมื่อใช้ถึง 80%
- **รายการประจำ** — ค่าเช่า/เงินเดือน ลงให้อัตโนมัติทุกเดือน
- **⚙️ ตั้งค่า** — แก้หมวดหมู่ (ใส่อีโมจิหน้าชื่อได้ เช่น “☕ กาแฟ”), บัญชี, งบ, รายการประจำ
- **สรุปทางอีเมล** ทุกวันอาทิตย์ 19:00 พร้อมแนบ **PDF สรุป** (รหัสเปิดไฟล์ = “รหัสเปิด PDF” ที่แต่ละคนตั้งเองในหน้าตั้งค่า)
- **สรุป PDF** ดาวน์โหลดในแอป (ตั้งค่า → สรุป PDF) เลือกช่วงวันที่ได้ — ต้องตั้ง “รหัสเปิด PDF” ก่อน
- Android: กด "แชร์" รูปสลิปจากแอปธนาคาร → เลือก **เป๋าตังค์** ได้เลย (หลายรูปก็ได้)
- **หลายผู้ใช้** — สมัครเอง ยืนยันอีเมลแล้วใช้ได้ทันที ไม่ต้องรออนุมัติ · ลืมรหัสผ่านรีเซ็ตเองทางอีเมล · ข้อมูล/ตั้งค่า/สลิป/อีเมลสรุป/PDF แยกตามคน
- **หน้าจัดการผู้ใช้ (ผู้ดูแล)** — ระงับ/เปิดใหม่, ตั้งผู้ดูแลเพิ่ม, ลบบัญชีพร้อมข้อมูล (คนแรกที่สมัครเป็นผู้ดูแลอัตโนมัติ)
- **คีย์ AI ของแต่ละคน** — ผู้ใช้ใส่คีย์ Gemini ของตัวเองในหน้าตั้งค่า (หรือผู้ดูแลตั้งคีย์กลางให้ทุกคนใช้)

## สำหรับผู้ดูแล: ติดตั้งครั้งเดียว
ต้องมีบัญชี **Google**, **GitHub** (https://github.com/signup) และ **Vercel** (https://vercel.com/signup → *Continue with GitHub*) ใช้เวลาประมาณ 15–20 นาที ทำบนคอมพิวเตอร์จะง่ายที่สุด

### ขั้นที่ 1 เตรียม Google Sheet (ที่เก็บข้อมูลของทุกคน)
1. เปิด https://sheets.new เพื่อสร้าง Google Sheet ใหม่ ตั้งชื่อเช่น `เป๋าตังค์`
2. เมนู **ส่วนขยาย (Extensions) → Apps Script**
3. ลบโค้ดเดิมทั้งหมด แล้ววางโค้ดจากไฟล์ [`apps-script/Code.gs`](apps-script/Code.gs) (เปิดไฟล์ → กด *Copy raw file*) → กดบันทึก 💾 **ไม่ต้องแก้อะไรในโค้ด**
4. ที่แถบด้านบน เลือกฟังก์ชัน **`setup`** → กด **Run (▶)**
   - กด **Review permissions** → เลือกบัญชี Google ของคุณ
   - ถ้าขึ้น *Google hasn't verified this app* ให้กด **Advanced → Go to … (unsafe) → Allow** (ปกติสำหรับสคริปต์ในบัญชีของคุณเอง)
5. ดูที่ **Execution log** จะเห็น `รหัสลับ (APPS_SCRIPT_SECRET) ของคุณคือ: ...` → คัดลอกเก็บไว้ (**อย่าส่งให้ใคร**)
6. กด **ทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้รายการใหม่** → ⚙️ เลือก **เว็บแอป**
   - ดำเนินการในฐานะ: **ฉัน (Me)**
   - ผู้มีสิทธิ์เข้าถึง: **ทุกคน (Anyone)**
   - กด Deploy แล้วคัดลอก **URL ของเว็บแอป** (ลงท้ายด้วย `/exec`)

> "ทุกคน" แปลว่าเรียก URL ได้จากอินเทอร์เน็ต แต่สคริปต์ตอบเฉพาะคำขอที่มีรหัสลับเท่านั้น ลืมรหัสลับ: Run ฟังก์ชัน `showSecret`

### ขั้นที่ 2 สร้างโปรเจกต์ Supabase (ระบบสมัคร/เข้าสู่ระบบ)
Supabase เก็บแค่ **บัญชีเข้าสู่ระบบ** (อีเมล + รหัสผ่านตัวเลข 6 หลัก) ส่วนรายการและสลิปยังอยู่ใน Google Sheet/Drive ของคุณ

**2.1 สร้างโปรเจกต์** — https://supabase.com → **New project** (แผนฟรีใช้ได้) ตั้งชื่อและรหัสผ่านฐานข้อมูล (เก็บไว้ แต่แอปนี้ไม่ได้ใช้) ส่วน Security: ติ๊ก *Enable Data API* ไว้, **เอาติ๊ก *Automatically expose new tables* ออก**, ติ๊ก *Enable automatic RLS* แล้วกด Create

**2.2 คัดลอกคีย์ 2 ค่า** — กดปุ่ม **Connect** ด้านบน (หรือ **Project Settings → API Keys**)
- **Project URL** เช่น `https://xxxx.supabase.co` → ใช้เป็น `SUPABASE_URL`
- **Publishable key** (ขึ้นต้น `sb_publishable_…`) หรือ **anon key** (ขึ้นต้น `eyJ…`) → ใช้เป็น `SUPABASE_ANON_KEY`
- ห้ามใช้ `secret` / `service_role` key ในช่องนี้

**2.3 ตั้งค่าการสมัคร** — เมนู **Authentication**
1. **Sign In / Providers → Email:** เปิด *Enable Email provider*, เปิด **Confirm email**, ความยาวรหัสผ่านขั้นต่ำปล่อยค่าเริ่มต้น 6 (แอปบังคับให้เป็นตัวเลข 6 หลักเอง) และอย่าตั้งเงื่อนไขตัวอักษรพิเศษ/ตัวพิมพ์ใหญ่ และให้ *Allow new users to sign up* เปิดอยู่
2. **URL Configuration:** ใส่ **Site URL** = ที่อยู่แอปของคุณ เช่น `https://paotang-xxxx.vercel.app` (ไม่มี `/` ปิดท้าย) และเพิ่มที่อยู่เดียวกันใน **Redirect URLs** — ถ้ายังไม่ได้ติดตั้ง Vercel ให้ทำขั้นที่ 3 ก่อนแล้วกลับมาใส่ข้อนี้
3. **Email Templates:** แก้ 2 แบบ โดยเปลี่ยนปุ่ม/ลิงก์ในเนื้อหาเป็นดังนี้ (ข้อความอื่นแก้เป็นภาษาไทยได้ตามใจ)

   **Confirm signup** — ลิงก์:
   ```html
   <a href="{{ .SiteURL }}/auth/confirm?token_hash={{ .TokenHash }}&type=signup">ยืนยันอีเมล</a>
   ```
   **Reset password** — ลิงก์:
   ```html
   <a href="{{ .SiteURL }}/auth/confirm?token_hash={{ .TokenHash }}&type=recovery&next=/reset">ตั้งรหัสผ่านใหม่</a>
   ```
   ต้องใช้ลิงก์นี้เท่านั้น (ห้ามใช้ `{{ .ConfirmationURL }}` ที่เป็นค่าเริ่มต้น) ไม่เช่นนั้นกดลิงก์ในอีเมลแล้วเข้าสู่ระบบไม่ได้

**2.4 ตั้ง SMTP ของคุณเอง** — **Authentication → Emails → SMTP Settings** (ชื่อเมนูอาจต่างเล็กน้อย) ตัวส่งอีเมลเริ่มต้นของ Supabase จำกัดไม่กี่ฉบับต่อชั่วโมง ใช้ทดสอบได้ แต่ไม่พอสำหรับผู้ใช้จริง ตัวอย่างฟรี: [Resend](https://resend.com) (ต้องยืนยันโดเมนของคุณ) หรือ [Brevo](https://www.brevo.com) — เอาค่า host / port / username / password ที่ผู้ให้บริการให้มากรอก

> โปรเจกต์ฟรีของ Supabase จะถูกพักเมื่อไม่มีการใช้งาน ~1 สัปดาห์ (กด Restore ได้) ถ้าใช้จริงจังควรพิจารณาแผนเสียเงิน

### ขั้นที่ 3 ติดตั้งแอปบน Vercel
[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Ftm-tmn%2FPaotangShare&project-name=paotang&repository-name=paotang&env=APPS_SCRIPT_URL%2CAPPS_SCRIPT_SECRET%2CSUPABASE_URL%2CSUPABASE_ANON_KEY)

| ชื่อ | ใส่อะไร |
|---|---|
| `APPS_SCRIPT_URL` | URL เว็บแอปจากขั้นที่ 1 ข้อ 6 |
| `APPS_SCRIPT_SECRET` | รหัสลับจากขั้นที่ 1 ข้อ 5 |
| `SUPABASE_URL` | Project URL จากขั้นที่ 2 |
| `SUPABASE_ANON_KEY` | anon / publishable key จากขั้นที่ 2 |

กด **Deploy** รอ 1–2 นาที จะได้ที่อยู่แอป เช่น `https://paotang-xxxx.vercel.app` → เอาไปใส่เป็น **Site URL** และ **Redirect URLs** ใน Supabase (ขั้นที่ 2.3 ข้อ 2) ด้วย

**ติดตั้งไว้แล้ว / แก้ค่าทีหลัง:** Vercel → โปรเจกต์ → **Settings → Environment Variables** ใส่หรือแก้ค่า (เลือกครบทั้ง Production / Preview / Development) แล้วไปที่ **Deployments → ⋯ → Redeploy** ค่าจึงจะมีผล

### ขั้นที่ 4 สมัครบัญชีผู้ดูแล
1. เปิด `https://<ที่อยู่แอป>/setup` ถ้าขึ้น ✅ ครบทุกข้อแปลว่าเชื่อมต่อสำเร็จ (ถ้า ❌ ที่ Supabase ให้ตรวจ URL / key ใน Vercel และ Redeploy; ถ้า Apps Script ยังไม่ใช่ v6 ให้วางโค้ดใหม่ตามหัวข้อ “อัปเดตเป็นเวอร์ชันใหม่”)
2. เปิด `https://<ที่อยู่แอป>/signup` สมัครด้วยอีเมลของคุณ → กดลิงก์ยืนยันในอีเมล — **บัญชีแรกที่สมัครจะเป็นผู้ดูแลอัตโนมัติ** (จึงควรสมัครเองก่อนแจกลิงก์ให้ใคร)
3. เข้าสู่ระบบ → ตั้งค่า → **👑 จัดการผู้ใช้**

### ขั้นที่ 5 ชวนคนอื่นมาใช้
ส่งที่อยู่แอปให้ เขากด **สมัครใช้งาน** → ยืนยันอีเมล → ใช้ได้เลย ไม่ต้องรออนุมัติ
- ใครลืมรหัสผ่าน: กด **ลืมรหัสผ่าน?** ที่หน้าเข้าสู่ระบบ ระบบส่งลิงก์ตั้งรหัสใหม่ทางอีเมล
- เลิกใช้: **ระงับ** (เก็บข้อมูลไว้) หรือ **ลบบัญชี** (ลบรายการทั้งหมดของคนนั้น รูปสลิปไปอยู่ในถังขยะ Drive 30 วัน) — ถ้าอยากลบล็อกอินใน Supabase ด้วย ให้ตั้ง `SUPABASE_SERVICE_ROLE_KEY` (ไม่บังคับ) ไม่เช่นนั้นลบเองที่ Authentication → Users

## สำหรับผู้ใช้
- **ติดตั้งบนมือถือ:** iPhone (Safari) ปุ่มแชร์ → *เพิ่มไปยังหน้าจอโฮม* · Android (Chrome) ปุ่ม *ติดตั้ง* ในแอป หรือเมนู ⋮ → *ติดตั้งแอป*
- **AI อ่านสลิป (ไม่บังคับ):** ตั้งค่า → AI อ่านสลิป → ใส่คีย์ Gemini ของตัวเอง (ขอฟรีที่ https://aistudio.google.com/apikey)
- **อีเมลสรุปรายสัปดาห์:** ตั้งค่า → ตั้ง *รหัสเปิด PDF* → ติ๊ก *ส่งสรุปรายสัปดาห์* → บันทึก (ส่งไปที่อีเมลที่ใช้สมัคร)

## ตั้งค่าเพิ่มเติมสำหรับผู้ดูแล (ไม่บังคับ)
ใส่ใน Vercel → **Settings → Environment Variables** แล้วกด **Redeploy**

| ชื่อ | ใช้ทำอะไร |
|---|---|
| `GEMINI_API_KEY` | คีย์ AI กลาง ให้ทุกคนที่ไม่ได้ใส่คีย์ของตัวเองใช้ร่วมกัน (โควตาฟรีหมดเร็วถ้าคนเยอะ) |
| `GEMINI_MODEL` | เปลี่ยนรุ่น AI (ค่าเริ่มต้น `gemini-3.8-flash` ถ้าไม่ว่างจะสลับรุ่นสำรองให้เอง) |
| `SUPABASE_SERVICE_ROLE_KEY` | (ไม่บังคับ) ให้ปุ่ม “ลบบัญชี” ลบล็อกอินใน Supabase ด้วย — เก็บเป็นความลับ ห้ามใส่ในโค้ด |
| `PIN_KEY` | ข้อความสุ่มยาว ๆ ใช้เข้ารหัส “รหัสเปิด PDF” ก่อนเก็บลงชีต (ถ้าไม่ตั้ง จะสร้างจาก `APPS_SCRIPT_SECRET`) |

> ⚠️ **ห้ามเปลี่ยน `APPS_SCRIPT_SECRET` (หรือ `PIN_KEY`) หลังมีผู้ใช้แล้ว** — “รหัสเปิด PDF” ของทุกคนถูกเข้ารหัสด้วยกุญแจนี้ ถ้าเปลี่ยน ทุกคนต้องตั้งรหัสเปิด PDF ใหม่

## ความปลอดภัยและความเป็นส่วนตัว
- **แยกข้อมูลตามคน:** ทุกคำขอตรวจสิทธิ์ที่เซิร์ฟเวอร์ ผู้ใช้เห็น แก้ ลบได้เฉพาะรายการและสลิปของตัวเอง
- **รหัสผ่านอยู่ที่ Supabase:** แอปและ Google Sheet ไม่เคยเห็นหรือเก็บรหัสผ่านเข้าสู่ระบบ (Supabase เก็บแบบแฮช) ลืมรหัสผ่านรีเซ็ตทางอีเมล
- **รหัสเปิด PDF ถูกเข้ารหัส:** เก็บลงชีตแบบเข้ารหัส (AES-256-GCM) กุญแจอยู่ที่ Vercel เท่านั้น
- **ยืนยันอีเมลก่อนใช้งาน:** กันการสมัครด้วยอีเมลของคนอื่น (ต้องเปิด Confirm email ใน Supabase)
- **ระงับมีผลทันที:** บัญชีที่ถูกระงับหรือลบจะใช้งานไม่ได้ แม้ล็อกอินค้างไว้
- **หน้าที่เห็นข้อมูลทุกคน (`/setup`, จัดการผู้ใช้) เปิดได้เฉพาะผู้ดูแล**
- **ผู้ดูแลเข้าถึงข้อมูลได้ทั้งหมด** ผ่าน Google Sheet/Drive ควรแจ้งผู้ใช้ให้ทราบ (หน้าสมัครมีข้อความแจ้งไว้แล้ว) และอย่าแชร์ชีตให้คนอื่น

## ข้อจำกัดของแผนฟรี
- **อีเมล:** บัญชี Gmail ทั่วไปส่งได้ประมาณ 100 ฉบับ/วัน (Google Workspace ประมาณ 1,500) — อีเมลสรุปรายสัปดาห์ส่ง 1 ฉบับต่อคนที่เปิดไว้ ดูโควตาที่เหลือได้ในหน้า `/setup`
- **ความเร็ว:** ทุกคนใช้ชีตเดียวกัน เหมาะกับหลักสิบคน / หลักหมื่นรายการ ถ้าคนเยอะหรือข้อมูลมากจะเริ่มช้า
- **พื้นที่สลิป:** ใช้พื้นที่ Google Drive ของผู้ดูแล (ฟรี 15 GB รวม Gmail/Photos) รูปสลิปถูกย่อเหลือประมาณ 100–400 KB ต่อรูป
