# เป๋าตังค์ 🐷💗

แอปบันทึกรายรับ–รายจ่ายบนมือถือ ติดตั้งไว้ที่หน้าจอโฮมได้เหมือนแอปทั่วไป แนบสลิปโอนเงินแล้วแอปอ่าน QR บนสลิปให้ (ธนาคาร + เลขอ้างอิง กันบันทึกซ้ำ) และเก็บรูปสลิปไว้ใน Google Drive ของคุณเอง

> **ข้อมูลของคุณอยู่กับคุณ 100%**
> แต่ละคนติดตั้งแอปเป็นของตัวเอง รายการเก็บใน Google Sheet และรูปสลิปเก็บใน Google Drive **ของบัญชีคุณเอง**
> ผู้แจกโค้ดนี้ **ไม่มีเซิร์ฟเวอร์กลาง ไม่เห็น ไม่เก็บ และไม่ดูแลข้อมูลของใคร**

**ใช้ฟรี:** Google (Sheet / Drive / Apps Script), GitHub และ Vercel แผนฟรีเพียงพอสำหรับใช้คนเดียว

## ฟีเจอร์
- **📎 สลิป** — เลือกได้หลายรูปพร้อมกัน แอปอ่าน QR (ธนาคาร + เลขอ้างอิง กันบันทึกซ้ำ) และถ้าเปิด AI จะอ่าน **ยอดเงิน วันที่ ชื่อผู้รับ และเดาหมวด** ให้อัตโนมัติ
- **＋ จดรายการ** — จดรายรับ/รายจ่ายที่ไม่มีสลิป
- **ดูตามวัน** — แถบเลือกวันใต้การ์ด (มีจุดสีประจำวัน + แถบบอกยอดจ่าย), หัวข้อแต่ละวันบอกวันในสัปดาห์ และทุกรายการแสดงเวลาที่บันทึก
- **ปฏิทินรายจ่าย** — ในหน้าสรุป สีชมพูเข้มตามยอดจ่ายของแต่ละวัน แตะวันเพื่อดูรายการวันนั้น
- **ธีมหวาน ๆ** — พาสเทลชมพู–ลาเวนเดอร์, กระจกใส, แอนิเมชัน, น้องหมูมาสคอต, หัวใจลอยตอนบันทึก, รองรับโหมดมืด
- **เปิดเร็ว** — จำข้อมูลล่าสุดไว้ในเครื่อง เปิดแอปเห็นทันทีแล้วค่อยซิงค์
- **แก้ไข / ลบ** — แตะรายการ → ✏️ แก้ไข (เปลี่ยนสลิปได้) หรือ ลบ
- **ค้นหาและตัวกรอง** — ค้นหาทุกเดือน, กรองตามประเภท หมวด บัญชี
- **บัญชี/กระเป๋า** — เช่น เงินสด, กสิกร, SCB — เลือกให้อัตโนมัติจากธนาคารในสลิป
- **📊 สรุป** — กราฟวงกลมตามหมวด, กราฟแท่ง 6 เดือน, ยอดแต่ละบัญชี
- **วงเงินใช้จ่ายต่อเดือน** — แถบบนหน้าหลัก บอกยอดที่เหลือและ "ใช้ได้อีกวันละกี่บาท" เตือนเมื่อถึง 80%
- **งบประมาณรายหมวด** — แถบความคืบหน้า และเตือนเมื่อใช้ถึง 80%
- **รายการประจำ** — ค่าเช่า/เงินเดือน ลงให้อัตโนมัติทุกเดือน
- **⚙️ ตั้งค่า** — แก้หมวดหมู่ (ใส่อีโมจิหน้าชื่อได้ เช่น “☕ กาแฟ”), บัญชี, งบ, รายการประจำ
- **สรุปทางอีเมล** ทุกวันอาทิตย์ 19:00 พร้อมแนบ **PDF สรุป** (รหัสผ่านเปิดไฟล์ = `APP_PIN`)
- **สรุป PDF** ดาวน์โหลดในแอป (ตั้งค่า → สรุป PDF) เลือกช่วงวันที่ได้ — ไฟล์ใส่รหัสผ่านเป็น PIN เดียวกับที่ใช้เข้าแอป
- Android: กด "แชร์" รูปสลิปจากแอปธนาคาร → เลือก **เป๋าตังค์** ได้เลย (หลายรูปก็ได้)

## สิ่งที่ต้องมี
- บัญชี **Google** (Gmail) — เก็บข้อมูลและสลิป
- บัญชี **GitHub** — สมัครฟรีที่ https://github.com/signup
- บัญชี **Vercel** — สมัครฟรีที่ https://vercel.com/signup (เลือก *Continue with GitHub*)

ใช้เวลาติดตั้งประมาณ 15–20 นาที ทำบนคอมพิวเตอร์จะง่ายที่สุด

## ขั้นที่ 1 เตรียม Google Sheet (ที่เก็บข้อมูล)
1. เปิด https://sheets.new เพื่อสร้าง Google Sheet ใหม่ ตั้งชื่อเช่น `เป๋าตังค์`
2. เมนู **ส่วนขยาย (Extensions) → Apps Script**
3. ลบโค้ดเดิมในหน้านั้นทั้งหมด แล้ววางโค้ดจากไฟล์ [`apps-script/Code.gs`](apps-script/Code.gs) (เปิดไฟล์ → กดปุ่ม *Copy raw file*) → กดบันทึก 💾 **ไม่ต้องแก้อะไรในโค้ด**
4. ที่แถบด้านบน เลือกฟังก์ชัน **`setup`** → กด **Run (▶)**
   - กด **Review permissions** → เลือกบัญชี Google ของคุณ
   - ถ้าขึ้น *Google hasn't verified this app* ให้กด **Advanced → Go to … (unsafe) → Allow** (ปกติสำหรับสคริปต์ที่อยู่ในบัญชีของคุณเอง)
5. ดูที่ **Execution log** ด้านล่าง จะเห็นบรรทัด `รหัสลับ (APPS_SCRIPT_SECRET) ของคุณคือ: ...` → คัดลอกเก็บไว้ (**อย่าส่งให้ใคร**)
6. กด **ทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้รายการใหม่ (New deployment)** → ⚙️ เลือก **เว็บแอป (Web app)**
   - ดำเนินการในฐานะ (Execute as): **ฉัน (Me)**
   - ผู้มีสิทธิ์เข้าถึง (Who has access): **ทุกคน (Anyone)**
   - กด Deploy แล้วคัดลอก **URL ของเว็บแอป** (ลงท้ายด้วย `/exec`)

> "ทุกคน" แปลว่าเรียก URL ได้จากอินเทอร์เน็ต แต่สคริปต์จะตอบเฉพาะคำขอที่มีรหัสลับของคุณเท่านั้น
> ลืมรหัสลับ: เลือกฟังก์ชัน `showSecret` แล้วกด Run

## ขั้นที่ 4 ติดตั้งบนมือถือ
- **iPhone (Safari):** เปิดที่อยู่แอป → ปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม**
- **Android (Chrome):** กดปุ่ม **ติดตั้ง** ในแอป หรือเมนู ⋮ → **ติดตั้งแอป**

## ตั้งค่าเพิ่มเติม (ไม่บังคับ)
ใส่ใน Vercel → โปรเจกต์ → **Settings → Environment Variables** แล้วกด **Redeploy**

| ชื่อ | ใช้ทำอะไร |
|---|---|
| `GEMINI_API_KEY` | ให้ AI อ่านยอดเงิน วันที่ ผู้รับ จากรูปสลิป — ขอฟรีที่ https://aistudio.google.com/apikey (รูปสลิปจะถูกส่งไปที่ Google เพื่ออ่าน) |
| `GEMINI_MODEL` | เปลี่ยนรุ่น AI (ค่าเริ่มต้น `gemini-3.8-flash` ถ้าไม่ว่างจะสลับรุ่นสำรองให้เอง) |
| `AUTH_SECRET` | ข้อความสุ่มยาว ๆ — ตั้ง/เปลี่ยนเมื่อต้องการให้ทุกเครื่องที่ล็อกอินค้างอยู่ถูกล็อกออก (เช่น มือถือหาย) |

**อีเมลสรุปรายสัปดาห์:** ในแอป → ตั้งค่า → ติ๊ก *ส่งสรุปรายสัปดาห์* → กด **บันทึกการตั้งค่า** → ลองกด **ส่งสรุปให้ดูตอนนี้**

## อัปเดตเป็นเวอร์ชันใหม่
- **แอป:** ที่รีโปของคุณใน GitHub กด **Sync fork** (ถ้าติดตั้งด้วยปุ่ม Deploy ให้คัดลอกไฟล์ใหม่ไปทับเอง) Vercel จะติดตั้งให้อัตโนมัติ
- **Apps Script:** วาง `Code.gs` ใหม่ทับ → บันทึก → Run `setup` อีกครั้ง (รหัสลับเดิมยังอยู่) → Deploy → **Manage deployments** → ✏️ → Version: **New version** → Deploy (URL เดิมใช้ต่อได้)

## ความปลอดภัยและความเป็นส่วนตัว
- **ข้อมูลอยู่ในบัญชีของคุณ:** รายการอยู่ใน Google Sheet และสลิปอยู่ในโฟลเดอร์ `เป๋าตังค์ - สลิป` ใน Google Drive ของคุณ เปิดดู แก้ หรือลบเองได้ตลอด
- **ไม่มีคนกลาง:** แอปบน Vercel เป็นของคุณเอง คุยกับ Google ของคุณโดยตรง ผู้แจกโค้ดเข้าถึงไม่ได้
- **ล็อกเมื่อไม่ได้ใช้งานเกิน 5 นาที:** กลับมาจะถูกถาม PIN ใหม่ ใช้งานต่อเนื่องไม่ถูกถาม
- **ใส่ PIN ผิด 5 ครั้ง ล็อก 15 นาที:** โดนซ้ำจะทบเวลาเป็น 30 นาที → 1 ชม. … สูงสุด 24 ชม.
- **ใช้ PIN 6–8 หลัก:** หน้า `/setup` จะเตือนถ้าสั้นกว่านั้น
- **รหัสลับอยู่ฝั่งเซิร์ฟเวอร์:** เก็บใน Vercel และ Apps Script เท่านั้น ไม่ถูกส่งไปถึงเบราว์เซอร์
- **ใช้ได้ทีละ 1 คน:** แต่ละการติดตั้งรองรับเจ้าของคนเดียว (PIN เดียว) ถ้าอยากให้คนอื่นใช้ ให้เขาติดตั้งชุดของตัวเองตามขั้นตอนนี้

## หมายเหตุเรื่อง PDF
- รหัสผ่านของ PDF คือ `APP_PIN` ถ้า PIN สั้น (เช่น 4 หลัก) การเข้ารหัสจะกันได้แค่คนที่เปิดไฟล์ผ่าน ๆ ไม่ใช่คนตั้งใจเจาะ — ยิ่ง PIN ยาวยิ่งปลอดภัย
- อีเมลรายสัปดาห์ให้ Apps Script ไปขอ PDF จากแอปด้วยรหัสลับเดียวกัน (Script จำที่อยู่แอปเมื่อกดบันทึกการตั้งค่า/ส่งสรุปครั้งแรก) ถ้าดึงไม่ได้อีเมลยังส่งตามปกติแต่ไม่มีไฟล์แนบ
- เปลี่ยน `APP_PIN` แล้ว PDF ใหม่จะใช้รหัสใหม่ทันที (ไฟล์เก่าที่ส่งไปแล้วยังใช้รหัสเดิม)

## โครงสร้าง
```
app/page.tsx              หน้าหลัก: สรุปรายเดือน + รายการ
app/login, app/setup      PIN และหน้าตรวจการเชื่อมต่อ
app/api/transactions      อ่าน/เพิ่ม/ลบรายการ + อัปสลิป (ผ่าน Apps Script)
app/api/slip/[id]         แสดงรูปสลิปจาก Drive
apps-script/Code.gs       โค้ดที่วางใน Apps Script ของชีต (เขียน Sheet + Drive)
app/api/scan              AI อ่านสลิป (Gemini)
app/api/settings          บันทึกการตั้งค่า / ส่งอีเมลสรุป
app/api/report            สร้าง PDF สรุป (pdfkit + ฟอนต์ Mali ใน assets/fonts) เข้ารหัสด้วย APP_PIN
components/               TxForm (เพิ่ม/แก้ไข + อ่านสลิป), DetailSheet, ListView, StatsView, SettingsView
lib/store.ts              ตัวเรียก Apps Script ฝั่ง server
lib/slipqr.ts             แกะ QR สลิป / พร้อมเพย์
lib/image.ts              ย่อรูป + สแกน QR ในเบราว์เซอร์ (jsQR)
proxy.ts                  ตรวจ session ทุก request
public/sw.js              service worker (offline shell + share target)
```
